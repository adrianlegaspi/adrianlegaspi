## Context

Since August 2022, I have worked on a centralized internal security dashboard tool at Viasat
that brings data from different scanners and asset sources into one connected model.
Viasat operates satellite communications infrastructure at global scale. The tool serves
multiple internal teams.

## What I did

- Architected and built the React and TypeScript security dashboard tool as the sole
  frontend engineer in a team of security and backend engineers.
- Owned the platform's email notifications in the Python backend, building the emails and
  connecting them to the sending services.
- Consumed and debugged the backend APIs from the frontend and made the required changes
  or fixes to the backend when needed.

## Technical highlights

Event-driven handlers bring new source data into one connected model, while Redis supports
hot read paths. Services run in Docker, with releases shipped through GitHub Actions across
the AWS environment.

## Outcome

The tool serves multiple internal teams. Proprietary implementation details, system names
and internal architecture are not published.
