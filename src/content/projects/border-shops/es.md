## Contexto

Construida en 2018 para el dueño de un restaurante que necesitaba gestionar la operación
diaria y planeaba ofrecer el servicio a otros negocios.

## El problema

El restaurante necesitaba una herramienta móvil para ventas e inventario. El producto
también necesitaba una base que pudiera crecer como servicio para otros operadores.

## Lo que hice

- Construí el cliente Android con Cordova.
- Desarrollé flujos de punto de venta e inventario para empleados.
- Construí el backend en PHP y MySQL que respaldaba la app móvil.

## Aspectos técnicos

Cordova entregaba el cliente móvil mientras PHP y MySQL manejaban los datos de negocio y
el backend de la aplicación.

## Resultado

El desarrollo terminó en 2020 cuando la pandemia de COVID-19 afectó el negocio del
restaurante. Las capturas archivadas muestran la app original.
