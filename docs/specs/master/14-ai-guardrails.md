## 50. Guardrails for AI Implementation

This project is expected to be implemented substantially with Codex and/or Claude.

The agent must follow these rules:

1. Do not expand scope beyond this document without a concrete requirement.
2. Do not replace the fixed camera with orbit/free-camera controls.
3. Do not render project case-study text inside WebGL.
4. Do not hardcode project-specific logic into generic city components.
5. Do not hardcode localized content inside scene components.
6. Do not create duplicate English/Spanish system metadata.
7. Do not introduce a backend unless a requirement actually needs one.
8. Do not create a CMS for MVP.
9. Do not add heavy post-processing before profiling.
10. Do not use screenshots or details from private work unless explicitly approved.
11. Maintain functional mobile navigation after every meaningful UI change.
12. Prefer a finished simple implementation over a speculative abstraction.
13. Keep project creation data-driven.
14. Validate project configuration.
15. Keep the city visually secondary to readable case-study content once a project is selected.
16. Avoid rewriting working systems merely to adopt a different library or pattern.
17. Treat the master spec as product requirements, not as permission to add adjacent features.
